## 雷达图 Canvas 线条不显示修复

用户反馈天气心情雷达图的线条没有展示出来。

根因：SVG 在微信小程序中兼容性差，已改为 Canvas 2D API 绘制，但存在三个问题：
1. **时序问题**：radarHasData 从 false 变 true 时，canvas DOM 节点可能尚未就绪，createSelectorQuery 找不到节点直接 return
2. **未使用 DPR**：Canvas 2D API 需要设备像素比保证清晰渲染
3. **线条太细**：lineWidth 0.3 在缩放坐标系中过细

已落地（pages/insights/insights.js）：
1. setData 回调中加 `setTimeout(() => this.drawRadarCanvas(), 80)` 延迟执行
2. drawRadarCanvas 增加重试机制：canvas 节点未找到时重试最多 6 次，每次间隔 100ms
3. 使用 `wx.getWindowInfo().pixelRatio` 获取 DPR，canvas 内部分辨率 = 100 * 5 * dpr
4. 加粗所有线条：网格 0.3→0.4、平均线 0.5→0.6、实际心情线 0.8→1.0
5. 加深颜色：网格 #F3E6DD→#E8D8CE、平均线 #C5B6AC→#B5A69C
6. 顶点圆点加大（0.8/1.5→1.0/1.8）并加白色描边增强可见度
7. 字体从 2.5px 增大到 3px

修改文件：
- pages/insights/insights.js
